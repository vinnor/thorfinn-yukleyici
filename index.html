thorfinn uploader

thorfinn uploader, thorfinn YouTube kanalının sahibinin kendi bilgisayarında çalıştırdığı kişisel bir masaüstü aracıdır. Kanal sahibinin kendi hazırladığı videoları YouTube Data API ile kendi kanalına yükler; başlık, açıklama, etiket ve yayın zamanını ayarlar. Başka kullanıcılara sunulmaz, satılmaz ve başka hiçbir kanala erişmez.

thorfinn uploader is a personal desktop tool run only by the owner of the thorfinn YouTube channel on their own computer. It uses the YouTube Data API to upload the owner's own videos to the owner's own channel and to set titles, descriptions, tags and publish times. It is not offered to other users and does not access any other channel.
